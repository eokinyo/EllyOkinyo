# ellyokinyo.com

Source code for [ellyokinyo.com](https://ellyokinyo.com), the personal website of Elly Okinyo: research and projects, CV, and writing on economics and economic policy.

It is a static single-page site (HTML, CSS and plain JavaScript) hosted on Firebase Hosting. Articles live in `writing/`, one HTML page each.

## Articles with public code

- [A record month, a shrinking US corridor: what Kenya's 2026 remittance data are telling us](https://ellyokinyo.com/writing/kenya-remittances-2026.html): code in [kenya-remittances-2026](https://github.com/eokinyo/kenya-remittances-2026)
- [The 1% US tax is not the biggest cost of sending money to Kenya](https://ellyokinyo.com/writing/kenya-remittance-costs-2026.html): code in [kenya-remittance-costs](https://github.com/eokinyo/kenya-remittance-costs)

## Deploying

See [DEPLOY.md](DEPLOY.md). Site configuration and private files are not in this repository, so a fresh clone cannot be deployed as is.
